# Driver Dashcam Assist using MATLAB

## Overview

Driver Dashcam Assist is an AI-powered driver monitoring system developed using MATLAB. The project analyzes dashcam video streams to improve road safety by monitoring driver behavior and detecting potential risk factors in real time.

The system focuses on three critical safety functions:

* Driver Drowsiness Detection
* Seatbelt Usage Detection
* Mobile Phone Usage Detection

By leveraging computer vision, image processing, and machine learning techniques, the solution helps identify unsafe driving conditions and supports the development of intelligent driver assistance systems.

## Features

### Driver Drowsiness Detection

* Monitors the driver's eye state and facial behavior.
* Detects prolonged eye closure and signs of fatigue.
* Generates alerts when drowsiness is detected.

### Seatbelt Detection

* Identifies whether the driver is wearing a seatbelt.
* Uses image processing and object detection techniques.
* Supports safety compliance monitoring.

### Mobile Phone Detection

* Detects mobile phone usage while driving.
* Helps identify distracted driving behavior.
* Improves overall driver safety awareness.

## Technologies Used

## Project Workflow

1. Capture dashcam video.
2. Extract video frames.
3. Detect driver's face and key features.
4. Analyze eye status for drowsiness detection.
5. Detect seatbelt presence.
6. Detect mobile phone usage.
7. Generate safety alerts and monitoring results.
